# CV Projects Resources

This repository is now structured to be published directly with **GitHub Pages**.

## Current structure

- `/index.html` → Homepage listing all projects.
- `/projects/<project-name>/index.html` → Individual project pages.

## Publish on GitHub Pages

1. Open repository **Settings** → **Pages**.
2. Under **Build and deployment**, choose:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` (or your default branch)
   - **Folder:** `/ (root)`
3. Save. GitHub will publish the site URL after deployment.

## Add more projects in future

1. Create a new folder:
   - `projects/my-new-project/`
2. Add project page:
   - `projects/my-new-project/index.html`
3. Add a link entry in `/index.html` under the project list.
4. Commit and push.
